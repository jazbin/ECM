MODE: Startup and Precedence

1) Scope
This document is a project-agnostic "Codex operating rules" set intended to work
across repositories. It assumes each repository provides its own:
- goals (milestones), tasks (tickets), contracts/specs, and run scripts
- an authority/precedence order for resolving conflicts
If a repository provides local rules that conflict with this document, the repo's
local rules take precedence.

2) Source of Truth and Precedence
1. Treat the repository working tree as the complete instruction set.
   - Do not assume external context.
   - Prefer local contracts/specs/docs over memory or web sources.
2. Resolve conflicts by a defined authority order. A robust default is:
   (a) explicit user instructions for this repo
   (b) AGENTS.md (or equivalent "agent operating instructions")
   (c) RUNBOOK/ (operational procedures)
   (d) CONTRACTS/ (schemas, units, IO contracts)
   (e) PLANS/ (ExecPlans) and TASKS/ (tickets)
   (f) existing code + repo conventions
3. If a conflict remains:
   - choose the safest interpretation,
   - record the decision (decision log),
   - proceed with bounded change + verification.

3) Session Startup Checklist (every session)
1. Start a session log BEFORE other commands.
2. Record the "last user prompt" / goal for traceability.
3. Read the repo TODO list and current STATUS (what is active, what is blocked).
4. Ensure runtime environment is loaded before builds/runs (e.g., OpenFOAM env).
5. If you will modify external/solver sources, take a backup once per session.
6. Prefer structured outputs from functionObjects/scripts over fragile log parsing.
