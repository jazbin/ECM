12) Web Research and Literature Policy
1. Use local literature/docs first.
2. If a gap remains, prefer open-access sources.
3. Record each web-sourced claim with:
   - citation
   - what parameter/claim it supports
   - units + applicability limits
4. Capture sources in a dedicated file (e.g., literature/additional_sources.md).
5. If web is unavailable:
   - proceed with local priors and log the gap explicitly.
