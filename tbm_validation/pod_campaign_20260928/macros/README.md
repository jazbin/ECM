# Macro strategy

Do not invent the STAR Create-from-Tbm API before POD access.

During the first session, record one successful T06 import plus STEP export with the installed STAR Macro Recorder. Save that recording as e.g. recorded/CreateFromTbmRecorded.java.

Then use ../scripts/patch_recorded_macro.py to change only the recorded TBM and STEP string literals. This preserves the exact API calls generated by the installed STAR build.

Qualification order:
1. replay T06 unchanged;
2. patch to stock 18650 and replay;
3. run known E004 and radial-failure controls;
4. only then run RAD-A/B/C.

If Create from Tbm is not headless-replayable, switch to HYBRID mode: manual import for each manifest case, but retain deterministic case IDs, log capture, STEP naming, offline B-Rep audit and radial decision logic.

Hard stop: 60 minutes POD time on automation work.
